# Guide Acheteur — AfriSupply

## 1. Créer un compte
- Inscription avec email, mot de passe, nom, entreprise
- Confirmer l'email via le lien reçu (ou code OTP)
- Accès immédiat au catalogue et à la messagerie

## 2. Rechercher des produits
- Barre de recherche avec autocomplétion
- Filtrer par catégorie, prix min/max, disponibilité
- Trier par prix, note, date d'ajout
- Cliquer sur un produit pour voir la fiche complète + specs techniques
- Télécharger la fiche produit PDF (anonymisée si pas de commande payée)

## 3. Contacter un fournisseur
- Bouton "Contacter" sur chaque fiche produit
- La messagerie est 100% anonyme (noms masqués)
- Bouton "Demander prix livraison" → message pré-rempli avec votre localisation
- Les échanges de coordonnées (téléphone, email, WhatsApp) sont bloqués automatiquement

## 4. Demander un devis (RFQ)
- Bouton "Demander un devis" sur la fiche produit
- Remplir : quantité, lieu de livraison, prix cible (optionnel)
- Le fournisseur reçoit une notification et peut soumettre un devis
- Vous pouvez accepter ou refuser le devis

## 5. Commander
- Ajouter des produits au panier
- Passer au checkout → choisir le mode de paiement :
  - **Carte bancaire** (Stripe)
  - **Mobile Money** (MTN, Orange, Airtel)
- Option **Trade Assurance** : les fonds sont bloqués jusqu'à votre confirmation de réception
- Les commandes sont créées uniquement après confirmation du paiement

## 6. Suivi de commande
- Dashboard acheteur → liste des commandes
- Timeline de suivi : En attente → Confirmée → En traitement → Contrôle qualité → Expédiée → En transit → Livrée
- Quand livré : bouton "Confirmer la réception"
- Si Trade Assurance active : possibilité d'ouvrir un litige avant de confirmer

## 7. Évaluer un fournisseur
- Après réception confirmée, noter le fournisseur (1-5 étoiles)
- Critères : note globale, communication, qualité, respect des délais
- Les avis sont publics et contribuent aux badges du fournisseur

## 8. Gérer mon compte
- Profil : modifier nom, entreprise, ville, pays
- Changer l'email : OTP envoyé à l'ancien email → 24h de délai → activation
- Changer le mot de passe
- Voir mes favoris, factures, notifications

## 9. Sécurité
- Toutes vos données personnelles sont masquées aux fournisseurs
- Les tentatives de contact hors-plateforme sont bloquées et signalées
- Paiement sécurisé Stripe + Trade Assurance
